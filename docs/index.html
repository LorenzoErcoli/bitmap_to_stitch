Bitmap To Stitch

Converti bitmap in tracciati SVG per ricamo. Puoi usarlo subito online nel browser oppure scaricare l'app locale per lavorare piu velocemente con file grandi.

Usa online Scarica app locale Vedi release

Quale versione usare

  1. Usa online: non installi nulla, ideale per test rapidi e immagini leggere.
  2. App locale: consigliata per conversioni piu grandi e piu veloci.

Installazione app locale

  1. Scarica BitmapToStitch-Windows.zip.
  2. Estrai la cartella zip.
  3. Avvia BitmapToStitch.exe.
  4. Il browser si aprira' su http://127.0.0.1:8765/.

Al primo avvio Windows potrebbe mostrare un avviso SmartScreen per app non firmate. Per rimuoverlo serve una firma digitale del programma.
