Bitmap To Stitch

App locale per convertire bitmap in tracciati SVG per ricamo. Il motore gira sul computer dell'utente: le immagini non vengono caricate online.

Scarica per Windows Vedi release

Installazione

  1. Scarica BitmapToStitch-Windows.zip.
  2. Estrai la cartella zip.
  3. Avvia BitmapToStitch.exe.
  4. Il browser si aprira' su http://127.0.0.1:8765/.

Al primo avvio Windows potrebbe mostrare un avviso SmartScreen per app non firmate. Per rimuoverlo serve una firma digitale del programma.
