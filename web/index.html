Guida parametri

Ogni valore influenza numero punti, copertura e tempi macchina.

Bitmap

Immagine di partenza da convertire.

Max width (px)

Ridimensiona la larghezza. 0 = nessun resize.

Soglia (0-255)

PiÃ¹ alta = include piu pixel scuri; piu bassa = selezione piu stretta.

Sample colors

Lista colori target (es. #000000,#FF0000). Vengono aggiunti alla selezione basata su soglia.

Sample tolerance

Tolleranza RGB per il campionamento colore (0 = match esatto).

Escludi sfondo

Rimuove dalla selezione i colori indicati come sfondo. Disattivalo se il bianco e' un filo da ricamare.

Background colors

Lista colori da ignorare come sfondo, ad esempio #FFFFFF.

Background tolerance

Tolleranza RGB per eliminare sfondi quasi bianchi o leggermente colorati.

Numero colori

Quantizzazione colori dell'immagine (1-12).

Max points

Tetto globale punti. 0 = nessun tetto.

Densita globale (%)

Percentuale di punti da mantenere sul totale. 0 = disattivata.

Scala SVG

Moltiplicatore coordinate SVG (dimensione finale).

Analysis square (mm)

Regolarizza i punti su quadrati in mm (se attivo, minimo 1 mm).

Default DPI

Usato per conversioni mm quando il file sorgente non ha metadati DPI.

Stroke width

Spessore linea in SVG per preview/esportazione.

Min dist (mm)

Distanza minima reale in millimetri tra punti consecutivi (filtra addensamenti).

Reinsertion rounds

Tentativi di reinserimento punti filtrati dal min dist.

Path chunk size

Divide il tracciato in blocchi per alleggerire file grandi.
