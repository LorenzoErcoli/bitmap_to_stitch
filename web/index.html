Bitmap → Stitch (Web)

Carica un'immagine (anche a colori) per generare direttamente nel browser tracce SVG pronte per la macchina da ricamo, una per ogni tinta.

Impostazioni generali
Stile e ordinamento

Le opzioni vengono applicate in base allo stile selezionato (carpet o degradé).

Scarica SVG (monocolore) Scarica SVG multicolore

Avanzamento: 0%

Carica un'immagine per iniziare.

Guida parametri

Ogni valore influenza numero punti, copertura e tempi macchina.

Bitmap

Immagine di partenza da convertire.

Max width (px)

Ridimensiona la larghezza. 0 = nessun resize.

Soglia (0-255)

Più alta = include piu pixel scuri; piu bassa = selezione piu stretta.

Numero colori

Quantizzazione colori dell'immagine (1-12).

Max points

Tetto globale punti. 0 = nessun tetto.

Densita globale (%)

Percentuale di punti da mantenere sul totale. 0 = disattivata.

Scala SVG

Moltiplicatore coordinate SVG (dimensione finale).

Analysis square (mm)

Regolarizza i punti su quadrati in mm (se attivo, minimo 1 mm).

Stroke width

Spessore linea in SVG per preview/esportazione.

Min dist

Distanza minima tra punti consecutivi (filtra addensamenti).

Reinsertion rounds

Tentativi di reinserimento punti filtrati dal min dist.

Path chunk size

Divide il tracciato in blocchi per alleggerire file grandi.

Stile

Carpet = regolare; Degrade = casuale.

Ordering

Scanline = ordinato per righe; Nearest = percorso vicino-vicino.

Scanline band (px)

Altezza banda in modalità scanline.

Serpentina

Alterna direzione per banda (meno salti lunghi).

Grid cell (px)

Solo Carpet: regolarizza la distribuzione su griglia.

Drop probability (0-1)

Solo Degrade: probabilità di scartare un punto.

Jitter (px)

Solo Degrade: spostamento casuale massimo per punto.

Seed (facoltativo)

Solo Degrade: fisso per risultati ripetibili.
